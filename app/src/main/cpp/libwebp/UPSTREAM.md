# Upstream source

This directory contains the upstream libwebp 1.6.0 source, checked out from tag `v1.6.0` at commit `4fa21912338357f89e4fd51cf2368325b59e9bd9`.

Upstream: https://github.com/webmproject/libwebp

The upstream `COPYING` and `PATENTS` notices are retained in this directory. The Android build uses the upstream CMake project and builds the codec, mux and demux libraries as static dependencies of `animated_webp`.
